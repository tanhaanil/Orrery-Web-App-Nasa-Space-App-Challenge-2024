# Cosmic Chronicles

**Cosmic Chronicles** is an interactive web-based 3D orrery developed by **Team Space Mavericks** for the **NASA Space Apps Challenge 2024**. The project reimagines the traditional orrery as an interactive digital experience, allowing users to explore the solar system, planetary motion, the Moon's orbit, asteroids, and comets.

The application combines **interactive 3D visualization, NASA data, educational content, and gameplay** to make astronomical concepts easier and more engaging to explore.

The project focuses on creating an accessible and interactive way to understand the solar system and **Near-Earth Objects (NEOs)**. Users can explore celestial bodies, observe their orbital movements, learn about potentially hazardous asteroids, and interact with an educational planetary-defense game inspired by NASA's DART mission.

### Key Features

* **Dynamic 3D Orrery** - Interactive visualization of the solar system and celestial orbits.
* **Planetary Exploration** - Explore planets and access information about different celestial bodies.
* **Asteroid & Comet Tracking** - Visualize Near-Earth Objects using NASA data.
* **Educational Content** - Learn about the solar system and NEOs through interactive resources.
* **Planetary Defense Game** - An educational game inspired by NASA's DART mission.
* **Interactive Learning** - Educational content is integrated into the experience before users access the game features.

## UI/UX Design

The entire **UI/UX design of Cosmic Chronicles was designed by me** using Figma.

As the requirement was to build a custom orrery model, I had to learn a 3D rotating effect, which led me to build the entire solar system from scratch in a pseudo-3D format. Then, I learned how to drag information into the horizontal sliding frames automatically using a NASA API.
To give the app a more interactive 3D effect, I implemented a carousel discovery view, which allows users to observe and learn information while navigating between planets like Mercury, Earth, and Venus. I also included a dedicated asteroid page where users can learn about hazardous asteroids that could potentially harm Earth, along with a direct gateway to the official NASA asteroid page to discover different asteroid types. To portray the hazardous conditions of these near-Earth objects, I spent extra time figuring out how to visualize the simulation interactively, specifically showing how they encounter planets while rotating.
Moreover, I introduced a gaming-type segment where users can physically explore the planetary system by tapping or controlling a spaceship. Finally, I integrated all necessary NASA links that align directly with our app so that users don't have to go anywhere else to dive deeper into space exploration.
